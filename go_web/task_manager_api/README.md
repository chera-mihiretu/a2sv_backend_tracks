# Tast Manager API with GO 

## - features
    - Lists all tasks
    - Get The Detail of Specific Task 
    - Update Specific Task 
    - Delete Specific Task 
    - Create new Task 

####   Here is how we going to do it 
    - GET /tasks/ for listing the tasks
    - GET /tasks/:id to get detail of specific task
    - PUT /tasks/:id update task. Also accepts JDON body 
    - DLETE /tasks/:id to delete specific task 
    - POST /tasks/ accopts JSON body
